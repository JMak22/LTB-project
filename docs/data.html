02 / Reading the data

A few things to know about the data..

The LTB has not reported the same information in the same way every year. Here are a few things to keep in mind when comparing years.

Missing ≠ zero

If the LTB reported zero, the dataset says zero. A blank usually means the information wasn't reported or couldn't be reconstructed.
Ex. when application defaults were no longer tracked.

Definitions can change

A measure or application category may not mean exactly the same thing throughout the entire 27-year period.
Ex. when time-to-hearing was tracked in days, then in business days.

Not everything uses the same time period

Most annual-report data use fiscal years. Other LTB data may use calendar years, quarters or other reporting periods.

Numbers sometimes get corrected later

If a later official report corrects an earlier number, this project uses the corrected value and notes the change where it matters.
(At least I hope I noted the change.)

Totals don't tell the whole story

Two years with similar application totals can have a different mix of application types.

Application counts measure volume, not difficulty

The number of applications tells us how much work entered the system. It doesn't tell us how difficult those cases were, how much staff time they required, or what they meant for the people involved.

03 / Provenance

Where did these numbers come from?

Most of the data in this project were transcribed or extracted from annual reports published by the Ontario Rental Housing Tribunal, Landlord and Tenant Board and Tribunals Ontario. More recent datasets also use information published through Ontario's Open Data catalogue.
Some files on this site are calculated from those reported values — for example, the L1 + L2 + L4 comparison. When the project calculates or combines values rather than reproducing a number directly from a source, that is identified in the accompanying notes.
For more about how the data were collected, checked and interpreted, see About & Methodology.
